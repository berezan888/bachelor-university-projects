# Eye Diseases Diagnostics

A rule-based expert system designed to assist users in identifying potential eye conditions based on their symptoms.

## 🛠️ Tech Stack & Tools
* **Development Tool:** ES-Builder
* **Domain:** Medical Diagnostics (Ophthalmology)

## 📂 Project Structure & Components
* `Documentation`: The complete technical and functional specification is provided in the `Diagnostika očných ochorení.pdf`.
* `Scheme`: The decision tree and inference network logic mapping symptoms to hypotheses and final conclusions.
* `System`: The "Diagnostika očných ochorení" expert system, built to evaluate user responses (numerical and yes/no questions) and recommend potential diagnoses or advise consulting an eye specialist.

## 🚀 Features
* Symptom-based questioning flow (vision quality, pain scale, redness, discharge, sensitivity to light, etc.).
* Inference engine mimicking expert medical reasoning.
* User-friendly interface designed for accessibility.
