# Dog Breed Selection

A rule-based expert system utilizing backward chaining in an inference network to assist users in finding the most suitable dog breed based on their living conditions and lifestyle preferences.

## 🛠️ Tech Stack & Tools
- **Development Language & Environment:** Python 3.x
- **Data & Visualization:** Pandas, CSV, Graphviz
- **Domain:** Expert Systems / Backward Chaining Inference

## 📂 Project Structure & Components
- `Documentation`: The complete technical and functional specification is provided in the `VÝBER VHODNÉHO PLEMENA PSA.pdf` file.
- `Scheme`: The decision tree and inference network logic provided in the `Decision Tree.jpg` file.
- `System`: The interactive expert system implemented in `Program.py`, using data from `dogs.csv` to evaluate user responses and suggest matching breeds.

## 🚀 Features
- Backward chaining inference engine for hypothesis verification.
- Flexible CSV-based knowledge representation of dog breeds.
- Interactive question-based interface evaluating suitability and compatibility percentages.
