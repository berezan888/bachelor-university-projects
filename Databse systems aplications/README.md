# 🗄️ Database Systems Applications

* **Languages & Tools:** SQL, PL/SQL
* **What I studied:** Database systems fundamentals, data modeling, relational data model, relational algebra, functional dependencies, normalization, primary and index file organization, transaction processing, and basic database security.
* **Goal:** Master the theoretical foundations of database systems and SQL/PL/SQL principles to work with database objects and build practical client-server database applications.
