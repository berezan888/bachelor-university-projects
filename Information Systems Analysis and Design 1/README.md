## 🚘 Semester Project: Auto Repair Shop Information System

Our team developed a comprehensive analysis and design documentation for a digital information system aimed at automating and optimizing customer service, order processing, inventory control, and financial operations of an auto repair shop.

### Key Project Phases & Documentation Structure:
1. **Current State & Problem Analysis:** 
   * Analyzed manual bottlenecks in client registration, paperwork, inventory tracking, and payment processing.
2. **Vision & Stakeholder Personas:** 
   * Created detailed user profiles and personas (e.g., *Adam Novák* as Shop Manager, *Tereza Dvořák* as Sales Manager, *Tomáš Novák* as Mechanic, and customers).
3. **Requirements Engineering (MoSCoW Method):** 
   * Defined functional and non-functional requirements (response time $<2$s, data encryption, secure access rights) and categorized them using Must/Should/Could/Won't have priorities.
4. **Process Modeling & Use Cases:** 
   * Built **UML Use Case diagrams** and detailed **BPMN 2.0 process models** for key scenarios (such as viewing services/prices, tracking order status, and retrieving company statistics/reports).
5. **UX Design & Prototyping:** 
   * Designed information architecture and **Low-Fidelity (Lo-Fi) UI prototypes** covering the landing pages, service catalog, user profiles, and galleries.
6. **Pilot Deployment Case:** 
   * Structured the three core deployment components: **Organization** (process automation), **People** (roles and responsibilities), and **Technology** (Oracle SQL, C++ backend, web/cloud infrastructure)[cite: 4].
